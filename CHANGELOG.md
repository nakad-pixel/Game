# Changelog

All notable changes to Idle Anime Ascension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-28

### 🎉 Initial Release

#### Added - Core Features
- **Combat System**: Auto-combat with 60 FPS rendering
- **Progression**: Level 1-99 with XP and gold earnings
- **Ascension System**: Permanent 1.5x multipliers per ascension
- **Characters**: 4 unique characters (Striker, Guardian, Mystic, Legendary)
- **Traits**: 30+ traits with 4 rarity levels (Common, Rare, Epic, Legendary)
- **Achievements**: 15 achievements with rewards

#### Added - Monetization
- **Shop System**: Gem purchases, boosts, and cosmetics
- **Battle Pass**: 30-tier system with free and premium tracks
- **Ad Rewards**: Watch ads for 5 gems (simulated)
- **Premium Currency**: Gems for various purchases
- **Cosmetics**: 6+ skins and themes

#### Added - Systems
- **Save/Load**: Auto-save every 10 seconds with 3-slot backup
- **Offline Earnings**: Up to 8 hours of accumulated rewards
- **Analytics**: Event tracking for all major actions
- **Leaderboards**: Global ranking system (backend)
- **Cloud Saves**: Optional sync to backend server

#### Added - UI/UX
- **Mobile Optimization**: Portrait mode, 48px touch targets
- **Battery Saver**: 30 FPS mode when unfocused
- **Notifications**: Toast messages for events
- **Settings Menu**: Sound, music, graphics quality controls
- **Multiple Modals**: Progression, Shop, Characters, Achievements

#### Added - Technical
- **PWA Support**: Installable, offline-capable
- **TypeScript**: Full type safety throughout
- **Vue 3**: Composition API with `<script setup>`
- **PIXI.js**: Hardware-accelerated rendering
- **Pinia**: Type-safe state management
- **Backend API**: Express server for leaderboards and cloud saves

#### Added - Documentation
- Comprehensive README with setup instructions
- Deployment guide for multiple platforms
- Contributing guidelines
- Quick start guide
- Launch checklist
- Project summary

#### Added - Legal
- Privacy Policy (COPPA compliant)
- Terms of Service
- MIT License
